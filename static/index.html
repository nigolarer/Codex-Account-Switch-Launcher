Welcome to Codex Switcher

A lightweight local profile switcher for Codex on macOS

Codex Switcher keeps several local Codex launch profiles ready so you can switch between accounts without rebuilding your workspace setup each time.

How it works
Launcher A uses the normal ChatGPT launch. B–F provide up to five isolated CODEX_HOME and Desktop data directories. Account names, quota notes, reset timers, Workspaces, and Skills are managed locally.
Local by design
Codex Switcher does not verify your OpenAI identity and does not read passwords or auth tokens. Your launcher metadata is stored only on this Mac.
You can open this guide again at any time from the ? button beside the title.
